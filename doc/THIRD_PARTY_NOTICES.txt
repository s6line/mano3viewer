本体のMITライセンスとは別に、それぞれのライセンス条件が適用されます。

Slint 1.17.1
------------
Slint Royalty-free Desktop, Mobile, and Web Applications License 2.0を選択しています。
ライセンス全文はSLINT-LICENSE.mdを参照してください。
帰属表示は右クリックメニューの「バージョン情報」、または「環境設定を開く」の「情報 / About・動作環境」に表示します。
https://slint.dev/

その他のライブラリ

利用者が別途用意するソフトウェア
------------------------------
以下は本配布物に含めていません。

- Microsoft Visual C++ Runtime: 起動前にMicrosoft公式のx64版をインストールしてください。
  https://learn.microsoft.com/ja-jp/cpp/windows/latest-supported-vc-redist
- Microsoft Edge WebView2 Runtime: PDFや文書本文の表示に使用します。
  https://developer.microsoft.com/microsoft-edge/webview2/
- 7-Zipの7z.dll: RAR・7zなどの書庫閲覧に使用します。
  7-ZipはLGPL-2.1以降、RAR展開部分にはunRARの追加制限が適用されます。
  https://www.7-zip.org/
  https://www.7-zip.org/license.txt

各ソフトウェアは提供元の条件に従って使用してください。
