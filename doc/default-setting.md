# 初期設定と操作一覧

新規設定で起動した場合の主要初期値です。既存の設定ファイルがある場合は、その値が優先されます。設定画面から変更してください。保存先の変更は次回起動から反映し、既存データは自動移動しません。

## 画像表示時のキー

初期は右綴じです。綴じ方向や設定によって左右の動作が変わります。文字入力中・ペインにフォーカスがある場合は、その場所の操作が優先されます。

| 操作 | 初期キー |
|---|---|
| 次／前へ | ←／→ |
| 1枚ずつ次／前へ | ↓／↑ |
| 大きく下／上へスクロール | PageDown／PageUp |
| 先頭／末尾 | Home／End |
| ページ指定 | Ctrl+N |
| 0～90%位置へ | 数字0～9（10%刻み） |
| 指定割合へ | Ctrl+% |
| まとめて進む／戻る | Alt+→／Alt+←（綴じ方向に連動） |
| 画像内の移動 | Shift+矢印 |
| 次／前フォルダー・書庫 | Ctrl+→／Ctrl+← |
| Filesの親移動 | 初期キーなし。Filesの「表示形式」の右のボタンで操作 |
| ページ表示方式の切替 | Space |
| 綴じ方向の切替 | Backslash |
| 拡大／縮小 | +／− |
| 縦横フィット／引き伸ばし | Z／X |
| 原寸／固定倍率／倍率方式切替 | C／V／B |
| ルーペ拡大／縮小／切替 | Ctrl++／Ctrl+−／Ctrl+L |
| 左／右ペイン切替 | F9／F12 |
| 左上／Bookmarkペイン切替 | Ctrl+T／Ctrl+B |
| フォーカス中の項目を開く | Enter |
| ファイルを開く／画像保存 | Ctrl+O／Ctrl+S |
| コピー／貼付け | Ctrl+C／Ctrl+V |
| 画像情報／コンテキストメニュー | Ctrl+I／Menu |
| 次のBookmarkリスト／追加 | Ctrl+G／Ctrl+D |
| 没入表示／没入全画面 | F10／F11 |

## マウス（画像表示面）

| 操作 | 初期動作 |
|---|---|
| 左ダブルクリック | 没入全画面の切替 |
| 左ドラッグ | 自由スクロール |
| 右クリック／右ドラッグ | メニュー／範囲選択 |
| ホイール上／下 | 前／次 |
| 左ボタン＋ホイール上 | ページ表示方式の切替 |
| 右ボタン＋ホイール上／下 | 拡大／縮小 |
| 中ボタンドラッグ | 範囲拡大 |
| 中ボタン長押し | 縦ドラッグで倍率変更 |
| 中＋右ボタン | 範囲拡大前の倍率へ戻す |

サイドボタンの初期割当はありません。ダブルクリック判定500 ms、ドラッグ開始4 px、長押し1000 msが初期値です。

## EPUB・Markdown・TXT本文

| 動作 | 初期値・操作 |
|---|---|
| 大きく進む／戻る | 画面の100%、←／→ |
| 中程度進む／戻る | 50%、Alt+←／Alt+→ |
| 少し進む／戻る | 10%、↓／↑、ホイール下／上 |
| 次／前の章 | Enter／Shift+Enter、左ボタン＋ホイール下／上 |
| ページ送り方式 | 割合。EPUBとMarkdown／TXTで別々に設定 |
| ページ送りで残す行数 | 1行。「行数を残す」選択時に使用、設定範囲0〜5行 |
| スムーズスクロール | ON |
| 縦書き・横書き | 自動 |
| EPUB表示 | 連続スクロール、複数章を連続表示 |
| EPUB本文／ルビ | 20 px／本文の50%、フォント未指定 |
| Markdown本文 | 16 px、フォント未指定 |
| 本文余白 | 上下左右24 px |
| 本文幅 | 90% |
| 行高／字間 | 170%／0 |
| Markdown目次の深さ | 2 |

左右は文書の綴じ・表示方向に連動します。PDFはWebView2内蔵ビューアの操作を使用し、上記の章送りや画像用フィットがすべて使えるわけではありません。

「行数を残す」は、設定画面「コンテンツ / 文書形式」のEPUB本文・Markdown本文で選びます。連続表示の大きい送りやPageDown／PageUpに適用され、残す行数0は画面を重ねずに送ります。Markdownの設定はTXTにも共通です。段組み・固定レイアウト・画像主体のEPUBやPDFは対象外です。複雑な組版では行高を基準に送るため、行の切れ目が合わない場合があります。

Filesの親移動は一覧の場所から一つ上へ戻り、入れ子の書庫では一段ずつ外側へ戻ります。移動先に画像があれば先頭を開きます。文書本文にフォーカスがある場合は割当キーで実行できません。旧「次／前サブフォルダー」の操作と初期キーCtrl+Shift+→／Ctrl+Shift+←は廃止しました。既存設定の割当は保持されますが実行されません。

アプリ側の右クリックメニューは、再度の右クリックや選択操作以外のキーで閉じます。修飾キーだけでは閉じません。Escapeで閉じても範囲選択は残ります。

## メモリ・サムネイル

画面のMB表記は原則MiB（1 MiB = 1,048,576 bytes）です。設定上の予算はWindowsが表示するプロセス全体の使用量を厳密に制限するものではありません。

| 項目 | 初期値 | 意味 |
|---|---:|---|
| アプリメモリ予算 | 自動、50% | 物理メモリの50%を基準とし、空きメモリの90%までに制限。手動MBは初期0で、自動設定を使用 |
| 画像デコード上限 | 2048 MiB | 画像展開の安全上限 |
| デコード済み画像キャッシュ | 512 MiB | 展開済み画像の保持枠 |
| 先読み | 自動、前方8枚・後方1枚 | 枚数は予算等に制約される |
| アニメーション逐次読込の閾値 | 16 MiB | 大きい画像を順次処理する基準 |
| アニメーション保持 | 8フレーム | 逐次処理時の保持数 |
| サムネイルサイズ | 小 | 初期表示サイズ |
| サムネイルディスク上限 | 1024 MiB | 生成・保存を優先するため一時的に超過し得る |
| サムネイル保持メモリ上限 | 64 MiB | サムネイル画像の保持枠。生成処理すべてのメモリではない |
| サムネイル先読み上限 | 128 MiB | 先読み用の保持枠 |
| サムネイル作業予算 | アプリ予算の1/32 | 読込み・展開等の作業枠 |
| PDF応答チャンク | 自動（設定値0） | 応答単位の上限を自動決定 |
| PDF初回全体応答上限 | 64 MiB | 設定範囲1～2048 MiB、実効値はアプリ予算の1/8まで |
| PDF Range方式 | 自動 | 動作確認したRuntimeに応じて判断 |

RARは辞書サイズによって作業メモリが増えます。辞書32 MiBの例では一覧分を除き作業枠144 MiB以上が必要です。すべてのRARに共通する固定下限ではありません。

PDF全体応答上限を上げると大きなPDFを開ける場合がありますが、メモリ消費も増えます。設定値を超えるメモリが必要になることがあるため、空きメモリに余裕を持たせてください。

キャッシュ削除は現在の保存先の管理対象サムネイルを削除します。今回の起動後に作った分だけではありません。確認後に開始し、中断できます。中断までに削除した分は戻りません。削除できなかったファイルがあると件数を表示します。

## 保存場所

| 対象 | 初期保存先 |
|---|---|
| 設定 | exe隣のmano3viewer.toml |
| Bookmark・履歴 | exe隣（データ保存先が空の場合） |
| サムネイル | ローカルで書込み可能ならexe隣のthumbnail-cache。利用できなければWindows一時領域へ退避 |
| 文書表示・一時展開 | Windowsの一時フォルダー内のmano3viewer専用session |
| 保存失敗ログ | 設定ファイル隣の.log（失敗時のみ） |

サムネイルの管理フォルダー名はmano3viewer-v2です。退避キャッシュは正常終了でも消えません。実際の保存先は「一覧 / サムネイル」で確認できます。一時sessionは正常終了時に削除しますが、異常終了時には残る場合があります。

相対指定は設定ファイルのフォルダーが基準です。起動オプションや環境変数で上書き指定した場合はその指定が優先されます。通常利用でこれらを設定する必要はありません。
