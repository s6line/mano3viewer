# 変更履歴

## 0.9.4-20261010

- 画像の拡大・縮小方式にBi-cubic、Lanczos3と5種類のWindows画像処理方式を追加しました。環境設定の「画像表示」から選べます。初期値は従来どおりBi-linearです。
- フィット時の拡大上限を1〜8倍で設定できるようにし、固定倍率の上限を32倍（3200%）に拡張しました。拡大を禁止している場合は1倍が上限です。
- 画像の拡大・縮小時に表示を再利用し、高品質な表示へ切り替わる際のちらつきを軽減しました。
- キー・ホイールなどで倍率を変えた後に別の設定を適用しても、現在の倍率方式を維持するようにしました。
- アニメーションWebPでWindowsの画像読込み機能を優先するようにしました。利用できない場合は従来の読込み方式へ切り替えます。フレームの表示時間と透明部分の処理も改善しました。

## 0.9.3-20261006

- EPUBの割合移動を、章ごとの表示ページ数を基準にする方式へ変更しました。初回は概算の位置へすぐ移動し、計測済みの値は後の操作から使います。
- 設定だけのメニューバーを廃止し、画像表示面・左右のペイン・文書本文の右クリックメニューへ「環境設定を開く」を追加しました。
- 使用しない旧設定項目を設定画面から除外しました。既存ファイルの値は保持します。
- 重複していた「次／前サブフォルダー」操作とCtrl+Shift+→／←の初期割当を廃止しました。前後フォルダー・書庫移動はCtrl+→／←を使います。旧割当は設定ファイルに保持しますが実行しません。

## 0.9.2-20261004

- EPUB・Markdown・テキストの連続表示に、ページ送りで0〜5行を残す方式を追加しました。
- Filesに親移動ボタンを追加しました。入れ子の書庫からは一段ずつ外側へ戻れます。
- 動作一覧で「没入モード（最大化）」と通常の「最大化」を区別しました。

## 0.9.1-20261002

Bookmark一覧にサムネイルなし／小／大の切替を追加しました。
　左ペインのファイル一覧/グリッドでサムネイル表示用に作成されるサムネイルキャッシュを利用するため、左ペインでサムネイル未表示（未作成）の場合、ブックマーク登録してもサムネイルは表示されません。
